# Paws & Brew Cloudflare Migration

This repository is the migration workspace for Paws & Brew Online Menu.

The recovered AppDeploy source is the source of truth for the migration. Cloudflare Worker and Pages implementations will be added separately after adapting and testing the original application flows.

Target infrastructure: Cloudflare Worker `paws-and-brew-menu`, D1 database `paws-brew-db`, binding `DB`, Asia/Manila timezone, PHP currency.
